# Template Selection — Expo (React Native)

Use this template when the user wants:
- A **mobile app** for iOS and/or Android
- An app they can preview on their phone with Expo Go
- A React Native app suitable for App Store / Play Store submission
- Cross-platform mobile + web from a single codebase

Prefer another template when:
- The user only wants a website or marketing page — use tradesperson-sp (HTML)
- The user wants a web app with no mobile requirement — use c-code-react-runner
